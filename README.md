One funny line, 200 characters or fewer, on any topic — a joke the judge reads head to head against the field.

## Entry

> My therapist says I use humor to deflect. I told her that's the funniest thing she's ever said to me.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (101 characters, one line).
